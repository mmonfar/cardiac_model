# Bundled fonts

Two variable-weight Latin-subset fonts, both licensed under the SIL Open Font
License 1.1 (full text in `OFL.txt`; the same licence text applies to both,
the copyright holders differ):

| File | Family | Source |
|---|---|---|
| `PlusJakartaSans-Variable.woff2` | Plus Jakarta Sans | https://github.com/tokotype/PlusJakartaSans, copyright 2020 The Plus Jakarta Sans Project Authors |
| `SpaceGrotesk-Variable.woff2` | Space Grotesk | https://github.com/floriankarsten/space-grotesk, copyright 2020 The Space Grotesk Project Authors |

These files keep their own licence and are not relicensed under AGPL-3.0-or-later.
The app embeds them in its page stylesheet so it never calls an external font service.
